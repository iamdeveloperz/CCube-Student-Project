## 프로젝트 여는 방법

1. 저장소를 받습니다.
   ```
   git clone <저장소 주소>
   ```
2. Unity Hub → **Add** → **Add project from disk** → 학생 폴더(예: `임세진`)를 선택합니다.
3. 표에 적힌 Unity 버전으로 엽니다. 처음 열 때는 `Library` 폴더를 새로 만드느라 몇 분 걸립니다.

> `Library`, `Temp`, `Logs`, `UserSettings`, `*.csproj`, `*.sln`은 Unity가 자동으로 다시 만들기 때문에 저장소에 올리지 않습니다. (`.gitignore` 참고)

## 임세진 — Zombie Survival

이세계 포털에서 나오는 좀비로부터 기지를 지키는 웨이브 디펜스 게임입니다.
1인칭으로 직접 총을 쏘고, 3인칭 건설 모드로 바꿔 터렛을 설치해 최대한 많은 웨이브를 버팁니다.

- 씬: `Assets/05_Scenes/Game.unity`
- 세진이가 작성한 스크립트: `Assets/03_Scripts/`

### 조작 방법

| 키 | 동작 |
| --- | --- |
| `SPACE` | 게임 시작 |
| `W` `A` `S` `D` | 이동 (1인칭) |
| 마우스 | 조준 |
| 좌클릭 | 1인칭: 권총 사격 / 3인칭: 터렛 설치 (50 Gold) |
| `V` | 1인칭 사격 모드 ↔ 3인칭 건설 모드 |
| `R` | 게임 오버 후 다시 시작 |

### 폴더 구분

| 폴더 | 내용 |
| --- | --- |
| `임세진_원본` | 세진이가 만든 상태 그대로 (수정 전 백업) |
| `임세진` | 원본을 바탕으로 모델·맵·UI를 입히고 동작하지 않던 부분을 고친 버전 |

### `임세진`에서 바뀐 점 (원본 대비)

세진이 코드는 최대한 그대로 두고, 필요한 부분만 조금 고치거나 더했습니다.

**스크립트**
- `BaseManager.GameOver()` — 두 줄 추가: 최고 웨이브 저장(`WaveManager.OnGameOver()`) + 게임 오버 화면 표시
- `ZombieAI` — `Start()` 추가: 웨이브가 오를수록 좀비 체력 +25
- `GameUI.cs` — 새로 추가: 시작 화면, 게임 오버 화면, 조준점, 조작 안내
- 나머지 스크립트는 코드 변경 없음 (한글 주석이 깨지지 않도록 인코딩만 UTF-8로 변환)

**모델 · 맵**
- 큐브로 만든 바닥/길/터렛 자리/기지를 숨기고 같은 위치에 모델과 텍스처를 배치 (원래 오브젝트는 그대로 남아 있음)
- 터렛: `Turret_Canon.prefab` (세진이 `Turret` 스크립트 + Sci-fi 캐논 모델)
- 좀비: URP 재질 때문에 분홍색으로 보이던 문제를 Built-in 재질로 수정
- 맵 가장자리 숲, 묘지, 폐차, 건물, 우주 기지, 포털 이펙트, 조명/안개 추가

**버그 수정 · 밸런스**
- 터렛 총알이 좀비 발밑을 노리다 바닥에 먼저 부딪혀 사라지던 문제 → 좀비 충돌체를 발밑까지 늘림
- 좀비가 기지 앞까지 걸어오도록 `WayPoint7` 추가
- 시작 골드 0 → 100, 권총 피해 10 → 25, 터렛 피해 15 → 25 (총알 속도 10 → 20)

## 이효준 — 미로 공포 게임

노란 벽으로 된 미로(백룸 느낌)에서 손전등 하나에 의지해 귀신을 피해 다니는 1인칭 공포 게임입니다.
화면이 픽셀처럼 뭉개져 보이는 것은 의도한 연출입니다 (카메라 → 100×100 렌더 텍스처).

- 씬: `Assets/Scenes/SampleScene.unity`
- 효준이가 작성한 스크립트: `Assets/Scripts/`

### 조작 방법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 달리기 |
| `Ctrl` | 웅크리기 |
| `SPACE` | 점프 |
| 마우스 | 시점 |
| 좌클릭 | 손전등 켜기 / 끄기 |
| `R` | 배터리 줍기 |

### 폴더 구분

| 폴더 | 내용 |
| --- | --- |
| `이효준_원본` | 효준이가 만든 상태 그대로 (수정 전 백업) |
| `이효준` | 원본을 바탕으로 귀신 모델·애니메이션, 가시 트랩을 넣고 손전등/시야 문제를 고친 버전 |

### `이효준`에서 바뀐 점 (원본 대비)

효준이 스크립트는 최대한 그대로 두었습니다.

**스크립트**
- `FPSController` — 한 줄 수정: `Start()`에서 `spawnPosition`을 두 번 저장하던 줄을 `spawnRotation` 저장으로 고침 (죽고 부활할 때 회전값이 (0,0,0,0)이 되던 버그)
- `DeathTrap.cs` — 새로 추가: 플레이어가 닿으면 `FPSController`의 `Die()` 호출 (가시가 주기적으로 튀어나오는 옵션)
- `GhostAnimator.cs` — 새로 추가: 귀신의 이동 속도에 맞춰 대기/걷기/달리기 애니메이션 전환
- `Enemy`, `Flashlight`, `BatteryPickup`, `Test` 는 변경 없음 (인코딩도 그대로)

**플레이어 · 점프**
- 플레이어 크기 1.75배 (카메라·손전등·충돌체 함께), 시작 높이 보정
- 점프가 약 9m까지 떠오르던 문제 → `jumpForce` 9 → 1.3 (점프 높이 m), `gravity` -9.81 → -20 (인스펙터 값만 변경)

**귀신**
- `Prefabs/enemy.prefab` — 캡슐 더미를 숨기고 `True_Clown` 피에로 모델(키 6m, 미로 벽 높이와 같음)과 `Hyojun/Ghost.controller`(Idle/Walk/Run 블렌드) 적용
- 닿으면 죽는 `KillZone` 트리거 추가 (기존 `OnCollisionEnter` 판정은 CharacterController 때문에 잘 안 걸리던 문제 보완)
- 어둡고 픽셀이 큰 화면에서도 형체가 보이도록 귀신 재질에 은은한 자체발광(Emission) 적용

**가시 트랩**
- `Prefabs/SpikeTrap.prefab` — 바닥판 + 테두리 + 붉은 경고판 + 가시 25개 (가시 메시는 `Hyojun/Spike.asset`)
- 가시가 1.8초 숨었다가 1.6초 튀어나오며, 튀어나와 있을 때 밟으면 죽음 (트랩마다 타이밍이 조금씩 다름)
- 씬의 `Traps` 아래에 6개 배치 (시작 지점·귀신·배터리와 떨어진 미로 통로)

**손전등 · 시야**
- 손전등 빛(`YellowLight`)이 오른쪽 아래 손전등 모델 방향으로 나가 화면 중앙에서 벗어나던 문제 → 빛의 위치/방향을 카메라 정중앙으로 맞춤 (손전등 모델 위치와 밝기·배터리 값은 그대로)
- 픽셀 해상도(100×100)는 의도한 연출이라 그대로 유지
